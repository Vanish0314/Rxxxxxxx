# 解释

1 → 被 2 打断（丢弃）

2 → 被 3 打断（丢弃）

3 → 后面有 1.2s 的空闲期（超过 1s），所以发射

4 → 源完成时总是发射（即使后面没有安静期）

# 对比

| 运算符       | 行为                                       |
| ------------ | ------------------------------------------ |
| **Throttle** | 保留**安静期后的最后一个值**（防抖的效果） |
| **Sample**   | 每隔固定时间取最近一个值（不管有没有事件） |
